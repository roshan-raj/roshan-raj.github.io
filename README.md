# Roshan Raj – Portfolio

A modern, interactive portfolio website for Roshan Raj, showcasing skills, experience, projects, and technical writings. Built with HTML, CSS, and JavaScript, featuring custom animations, theme toggling, and responsive design.

## Features

- **"Warm Studio" design:** Cream canvas, espresso type and a terracotta accent, set in Fraunces, Inter and JetBrains Mono.
- **Light & dark themes:** Follows the system preference, with a toggle that remembers your choice (warm espresso dark mode).
- **Editorial layout:** Hero with an at-a-glance facts strip, About plus toolkit, Experience timeline, Projects, Writing and Contact.
- **Projects from data:** Project cards are rendered from [`data/projects.js`](data/projects.js).
- **Subtle motion:** Scroll reveals and hover states that respect `prefers-reduced-motion`.
- **Accessible & responsive:** Semantic markup, skip link, keyboard focus styles and a mobile menu.

## Project Structure

```
favicon.ico
index.html
README.md
assets/
    logo.png
css/
    index.css
data/
    projects.js
js/
    index.js
```

- **index.html:** Main HTML file with all sections.
- **css/index.css:** Styles for layout, animations, and themes.
- **js/index.js:** Handles interactivity, animations, theme toggling, and dynamic content.
- **data/projects.js:** Project data for the showcase section.
- **assets/logo.png:** Logo image.

## Getting Started

1. **Clone the repository:**
   ```sh
   git clone https://github.com/roshan-raj/roshan-raj.github.io.git
   ```
2. **Open `index.html` in your browser.**
3. **Customize content:** Update project data in [`data/projects.js`](data/projects.js) and personal info in [`index.html`](index.html).

## Customization

- **Add/Update Projects:** Edit [`data/projects.js`](data/projects.js) for new projects.
- **Change Skills/Experience:** Modify the relevant sections in [`index.html`](index.html).
- **Styling:** Tweak [`css/index.css`](css/index.css) for colors, fonts, and animations.
- **Scripts:** Enhance or change interactivity in [`js/index.js`](js/index.js).
